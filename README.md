# Naevii Next.js Project

This is the actual generated starter codebase for a premium handmade jewellery website.

## Includes
- Next.js 15 + TypeScript
- Tailwind CSS theme
- Homepage, shop, product, custom order, checkout, account, admin pages
- Supabase helper files
- Razorpay helper files
- API route scaffolds
- Supabase SQL schema starter

## Run
1. npm install
2. cp .env.example .env.local
3. npm run dev
